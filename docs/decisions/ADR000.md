# ADR000 — Pre-Code Sheet: inference-stream

**Stage:** 1 — Paper (Forward Mode)
**Date:** 2026-10-11
**Status:** Draft

---

## 1. Demand Threshold

> The system must accept a request, process it through an LLM with a system prompt, and return a response that conforms to a defined output schema — reliably, across single calls, batch runs, and streaming.

---

## 2. Properties That Threaten It

| # | Property | Threat |
|---|----------|--------|
| P1 | LLM non-determinism | Output shape varies between runs; schema breaks silently |
| P2 | Prompt sensitivity | Small wording changes in system prompt shift output structure |
| P3 | API rate limits | Batch of 50 labeled prompts hits throttle; partial runs |
| P4 | Stream interruption | Partial chunks arrive; assembling them produces malformed output |
| P5 | Schema version drift | Schema definition changes mid-project; old outputs become invalid |
| P6 | Eval label mismatch | Labeled set ground truth misaligns with schema field names |

---

## 3. Predicted Symptoms

| Threat | Symptom |
|--------|---------|
| P1 | JSON parse error or missing required field in response |
| P2 | Eval scores drop across runs with identical inputs |
| P3 | Batch returns partial results; some items silent-fail |
| P4 | Final assembled stream output truncated or structurally broken |
| P5 | Old labeled-set responses fail validation against new schema |
| P6 | Eval pass rate artificially low due to field name mismatch |

---

## 4. The Guard

| Threat | Guard |
|--------|-------|
| P1 | Output schema validation (strict, not lenient) on every response |
| P2 | Versioned, immutable system prompt files; no inline edits |
| P3 | Batch retry with exponential backoff; per-item status tracking |
| P4 | Stream chunk accumulator + schema validation on final assembled output |
| P5 | Schema versioned alongside prompt; both pinned per run |
| P6 | Labeled set includes schema version tag; eval validates field alignment before scoring |

---

## 5. The Test for Each Guard

| Guard | Test |
|-------|------|
| Schema validation | Unit: valid input passes, invalid input raises; assert on required fields |
| Versioned prompts | Test: same prompt version produces stable output across 3 runs |
| Batch retry | Integration: simulate rate-limit error; assert retry fires and completes |
| Stream accumulator | Unit: feed mock chunks; assert assembled output matches schema |
| Schema + prompt pinning | Test: mismatched versions raise a version conflict error before execution |
| Eval field alignment | Test: labeled set loads against schema; assert all label keys exist in schema fields |
